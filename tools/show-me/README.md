# show-me 回饋看板（給 Angus）

agent 做完一批畫面後，會把截圖整理成一「輪」。你在瀏覽器逐張看、標出哪裡要改、寫幾句話，按送出，agent 就會照你的回饋修改。全程只在你自己的電腦上，不會上傳任何東西。

## 第一次準備（Windows，約 5 分鐘，只做一次）

1. 在專案資料夾開 PowerShell。
2. 執行 `pnpm install`（已裝過可略過）。
3. 執行 `pnpm exec playwright install chromium`（下載截圖用的瀏覽器，約 150 MB）。agent 截圖或你按「送出」時若出現「找不到 chromium」，就是少了這一步。

## 開啟看板

1. 執行 `pnpm show-me`，會印出網址：`http://127.0.0.1:8770`。
2. 用瀏覽器開這個網址。首頁會列出所有輪次，並顯示每一輪還剩幾張沒標、或有幾項等 agent 處理。
3. 點進最上面那一輪。若埠 8770 被占用，執行 `pnpm show-me -- --port 8771` 換一個。

## 怎麼看、怎麼標

- 最上方的摘要寫著「請你看什麼、要你決定什麼」。先讀這段。
- 上方一排縮圖是這一輪的所有畫面，圓點顏色是狀態：灰＝沒標、綠＝OK、紅＝要修改、藍＝有疑問。
- 在畫面上選工具再拖曳：
  - 矩形（R）：框出一塊區域。
  - 箭頭（A）：從起點拖到要指的地方。
  - 圖釘（P）：點一下，放一個編號。
  - 手繪（D）：按住滑鼠自由畫。
- 每個標注會有編號（1、2、3…）。在右邊清單的輸入框寫「這裡要改什麼」。點清單會高亮畫面上的標注；切到「選取」後點標注、按 Delete 可刪除。
- 右邊還有「整體留言」，以及三個狀態按鈕：OK（1）、要修改（2）、有疑問（3）。再按一次同一個按鈕會取消。
- 有「目標」參考圖的項目，工具列會多出三種檢視：只看現況、並排（目標｜現況）、疊圖（用滑桿調透明度）。標注都畫在現況截圖上。
- 縮放：「－」「＋」或「符合寬度」。
- 鍵盤：← → 換張、1／2／3 設狀態、R／A／P／D 換工具、Esc 取消。
- 你寫的東西會自動儲存（右上角顯示「已自動儲存」），關掉分頁也不會掉。

## 送出

1. 每一張都設好狀態後，上方狀態列會顯示「全部標完了，可以送出」；全部都是 OK 會顯示完成訊息。
2. 按右上角「送出本輪回饋」，確認後等幾秒（正在把標注畫進截圖）。
3. 看到「已送出」後，回到 agent 說「我送出回饋了」。送出後這一輪就不能再改，agent 處理完會開下一輪給你看。

## 給 agent 的資訊（你不用管）

- `pnpm show-me:capture --summary "…"`：截圖、建立新一輪。需要先 `pnpm dev`；截圖網址只能是 `http://127.0.0.1:3000` 這類本機直連網址，不可用 proxy 或 tailnet 網址（經代理的畫面不會 hydrate，截到的圖互動全死）。設定在 repo 根目錄 `show-me.config.json`。
- `pnpm show-me:feedback --latest`／`--resolve <輪次 id>`：讀取與標記處理完的回饋。
- 資料在 `.review/`（已 gitignore）：`reports/*.html`、`rounds/<id>/round.json`、截圖、`feedback.json`、`feedback.md`、`<item>.annotated.png`。
- `show-me.config.json` 的 item 欄位：`id`、`title`、`route`、`viewport`（預設 1280×800）、`description`、`waitFor`（等這個選擇器出現）、`steps`（`click`／`fill`／`press`／`wait`）、`fullPage`（預設 true）、`reference`（repo 內的參考圖路徑，例如 `local-data/…`）。
