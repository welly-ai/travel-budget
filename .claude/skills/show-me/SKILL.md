# show-me

讓 Angus（非工程師、原生 Windows）看得到、點得到、標得出你做了什麼，回饋再交回你處理。所有輸出遵守 AGENTS.md「回報原則」。

## 選哪一種

| 內容 | 做法 |
|---|---|
| 階段回報、成果報告、方案比較 | 報告頁：寫 HTML 到 `.review/reports/<name>.html` |
| 有畫面的變更要使用者驗收 | 截圖開新一輪：`pnpm show-me:capture` |
| 純澄清、問問題 | 純文字，不產頁面 |

指令（`package.json` 提供）：`pnpm show-me`（啟動看板，預設 `http://127.0.0.1:8770`）、`pnpm show-me:capture`、`pnpm show-me:feedback`。

## 報告頁

1. 寫進 `.review/reports/<name>.html`（檔名只用文字、數字、`.`、`_`、`-`），`<link rel="stylesheet" href="welly.css">`，用 `.wrap`、`.card`、`.pill` 等現成元件。
2. 結構固定，順序不可換：
   1. **第一屏**：下一步動作（使用者現在要做或要決定的事）＋目前進度（第 N 步／共 M 步）。
   2. **這次具體可用的成果**：每項附可點的路由或指令，例如「在 `/projects/P01` 改 Class，人天矩陣即時更新」。
   3. **細節**：表格、比較、原因。
3. 清單每組最多 5 項，多的分組。不寫開場白與總結客套。
4. 給使用者連結：`http://127.0.0.1:8770/reports/<name>.html`（先確認 `pnpm show-me` 在跑）。

## 截圖開新一輪

1. 先 `pnpm dev`，等 Ready。**截圖目標只能是 `http://127.0.0.1:3000`（本機直連）**，不可指向 proxy 或 tailnet 網址：經代理的 dev server 畫面看似正常，但不會 hydrate，互動全死且沒有錯誤訊息，截到的圖會誤導使用者。
2. 在 `show-me.config.json` 列出這次要看的 item（`id`、`title`、`route`、`viewport`；可選 `description`、`waitFor`、`steps`、`reference`）。只列這次改動相關的畫面。
3. `pnpm show-me:capture --summary "<本輪摘要>"`（可加 `--only home,detail`）。找不到 chromium 時它會直接失敗並給安裝指令 `pnpm exec playwright install chromium`。
4. 把印出的看板網址給使用者。

### 本輪摘要怎麼寫

1. **請你看什麼、要你決定什麼**（第一行，一句話）。
2. 本輪變更（最多 5 項，各附路由）。
3. 若有上一輪回饋，逐條回應：`#編號 → 已改／未改＋原因`（編號是使用者標注的 #n，項目以標題指名）。讓使用者一眼看到他的回饋被處理了。

### 有參考圖時

原 Excel 等目標畫面放在 `local-data/` 底下，在 item 設 `"reference": "local-data/xxx.png"`（只能是 repo 內路徑）。看板提供「只看現況」「並排（目標｜現況）」「疊圖」三種檢視；標注座標一律以現況截圖為準。

## 讀回饋並處理

1. 使用者說「我送出回饋了」，或你要接續上一輪時：`pnpm show-me:feedback --latest`。沒有輸出待處理輪次就不要猜，直接問使用者。
2. 讀印出的 `feedback.md`：最上面是「要處理」的項目（要修改、有疑問），OK 的收在最後一行一項。每個標注有編號、類型、原始像素座標、文字。
3. 讀該項列出的 `*.annotated.png`（標注已畫進截圖）與 `參考圖`（若有）。座標以截圖左上角為原點。
4. 逐條處理：一條一條改，「有疑問」的先回答再問是否要改。**不要因為覺得不重要就略過任何一條**；不做的要寫原因。
5. 處理完 `pnpm show-me:feedback --resolve <輪次 id>`，重新 `capture` 開下一輪，在摘要中逐條回應編號。
6. 全部都是 OK 時不必再開新一輪，告訴使用者完成了。

## 資料安全

- 看板與資料只在本機：伺服器只綁 `127.0.0.1`，資料在 gitignore 的 `.review/`。
- 截圖與回饋可能含公司資料：不分享到外部、不貼進 issue、PR、commit 訊息，也不要上傳到雲端服務或公開通道。
- 不改伺服器綁定位址、不開 tunnel 或代理。要給其他人看，請使用者自己決定。
- 參考圖與報告內容同樣依 AGENTS.md「資料分級」處理；真實公司名、廠區名、真實數字不得進入會提交的檔案。
